# Hardik Mehta — Portfolio

Starter structure for a GitHub Pages portfolio inspired by the visual direction we selected.

## Current architecture

- `index.html` — portfolio homepage
- `projects/project.html` — reusable project case-study template
- `styles.css` — shared visual system and responsive design
- `script.js` — presentation-viewer interactions
- `assets/images/` — project screenshots
- `assets/gifs/` — project demo GIFs
- `assets/icons/` — icons and logos
- `presentations/` — presentation assets

## Next content phase
