PROJECT 04 • EXCEL AUTOMATION

FMCG Reporting Automation

An automated Excel reporting workflow using Power Query and VBA to transform incoming data, refresh reports, and monitor reporting activity.

ExcelPower QueryVBAData Automation

Presentation

The project presentation will be embedded here.

02 · PROJECT OVERVIEW

Project Overview

This project automates a recurring FMCG reporting workflow that would otherwise require repeated data preparation and report refreshing.

Incoming Excel files are processed through Power Query, consolidated into reporting data, and refreshed through a VBA-controlled workflow.

The process also provides visibility into refresh activity through status information and an audit log.

REPORTING WORKFLOW OVERVIEWWorkflow screenshot or diagram will be added here.

03 · THE PROBLEM

The Reporting Challenge

Recurring Excel reports can become difficult to maintain when new files arrive regularly and the workflow requires repeated manual actions.

The reporting process needed a way to bring in new files, standardize the data, refresh consistently, and show whether the refresh completed.

GOALBuild a repeatable reporting workflow that reduces manual intervention and makes the refresh process easier to monitor.

13 · BUSINESS IMPACT / CONCLUSION

Business Impact / Conclusion

This project demonstrates how Excel can be used as more than a static reporting tool.

Power Query and VBA connect data preparation, report refreshing, and refresh monitoring into a more structured workflow.

The practical value is a more repeatable reporting process with easier refresh management and greater visibility into reporting activity.

POWER QUERY + VBAPower Query handles the data transformation layer while VBA provides automation and refresh control, turning a recurring Excel reporting task into a more structured workflow.
