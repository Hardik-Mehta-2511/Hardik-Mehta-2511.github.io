Book Intelligence RAG

A RAG-based application that uses web-scraped book data to let users interact with and query a structured book dataset.

02 · PROJECT OVERVIEW

Project Overview

Book Intelligence RAG is a retrieval-augmented application built around a web-scraped book dataset.

The project combines data collection, preparation, retrieval, and LLM-based interaction into a single workflow that allows users to query the underlying book information.

RAG APPLICATION OVERVIEWArchitecture and application overview will be added here.

03 · THE CHALLENGE

The Challenge

A scraped dataset can contain useful information, but a raw collection of records is not an intuitive way for users to explore that information.

The challenge was to turn the book dataset into an interactive experience where users could ask questions and receive responses grounded in the available book information.

08 · TECHNOLOGY

Technology

PythonRAGLLMWeb ScrapingStreamlit

Python was used to build the data and application workflow, while web scraping was used to collect the underlying book information.

The RAG and LLM components provide the retrieval and natural-language interaction layer, with Streamlit providing the application interface.

09 · PROJECT OUTCOMES

Why It Matters

The project demonstrates how a static web-scraped dataset can be transformed into an interactive information-retrieval experience.

Instead of requiring users to manually explore individual records, the application provides a natural-language interface for interacting with the available book information.
