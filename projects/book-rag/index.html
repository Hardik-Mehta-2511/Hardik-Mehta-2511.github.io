02 · PROJECT OVERVIEW

Project Overview

This project uses web-scraped book data from Books to Scrape and a RAG-based application.

The application allows users to interact with and query the book dataset.

03 · THE PROBLEM

The Challenge

A scraped book dataset is difficult to query on its own. This project adds a RAG-based application so users can interact with and query the available book information.
