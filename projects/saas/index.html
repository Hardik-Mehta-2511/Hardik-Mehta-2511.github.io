PROJECT 02 • EXPERIMENTATION

SaaS A/B Testing Analysis

A controlled A/B testing analysis evaluating the impact of an AI feature on conversion, engagement and user behavior.

PythonSQLTableauStatistics

Presentation

02 · PROJECT OVERVIEW

Project Overview

This project evaluates whether an AI-powered feature improves outcomes for a SaaS product.

The experiment is designed to support a product decision using conversion, engagement, and user-behavior evidence rather than assumptions about the feature.

03 · BUSINESS QUESTION

Business Question

Should the SaaS company implement the AI feature based on its impact on conversion, engagement, and user behavior?

Conversion indicates whether the feature supports the desired product outcome. Engagement and behavior help assess how users interact with it beyond the primary outcome.

04 · APPROACH / METHODOLOGY

Experiment / Methodology

CONTROL

Existing experience

The control group represents the current SaaS experience without the AI feature.

EXPERIMENT

AI feature enabled

The treatment group receives the AI-powered feature being evaluated.

WORKFLOW

From data to decision

MySQL, Python, A/B testing, and Tableau support the analysis workflow.

Users are evaluated through control and treatment groups, with behavioral and conversion metrics used to compare the experiences.

The final decision is based on statistical evidence and business relevance, not on directional movement alone.

100K SYNTHETIC EXPERIMENT DATASETAfter the initial 10K-user experiment did not provide sufficiently clear evidence for a decisive Control vs Treatment conclusion, the experiment was scaled to 100,000 randomly generated users using Python.Using a larger synthetic dataset allowed the experiment to evaluate the AI feature with greater statistical precision while keeping the Control and Treatment framework consistent.

05 · DATASET

Dataset

The project initially used a 10K-user dataset. That sample did not provide sufficiently clear statistical evidence for a decisive Control vs Treatment conclusion.

The final experiment used 100,000 users in a randomly generated synthetic dataset created with Python. Users were assigned to Control and Treatment groups for the experiment.

The larger synthetic dataset was used to improve the statistical power and precision of the comparison, with the aim of determining more clearly whether the AI feature produced a meaningful difference between the two groups.

WHY 100K?

Stronger evidence base

The dataset was scaled because the original 10K experiment did not produce a sufficiently clear winner.

DATA TYPE

Randomly generated

The 100,000-user experiment dataset was generated synthetically in Python and does not represent real customers.

EXPERIMENT FRAMEWORK

Control vs Treatment

The larger dataset kept the experiment groups consistent while supporting a more precise comparison.

Key Metrics

07 · STATISTICAL ANALYSIS

Statistical Analysis

The analysis compares outcomes between the control and treatment groups using the project’s defined A/B testing workflow.

Hypotheses, p-values, confidence intervals, and statistical significance should be read alongside practical business significance when interpreting the result.

The current project materials do not establish a confirmed significant winner or provide final test values, so those outputs remain part of the supporting analysis to be documented.

STATISTICAL TEST RESULTSHypothesis tests, confidence intervals, and result interpretation will be added here.

08 · KEY FINDINGS

Key Findings

EVIDENCE

No clear winner in 10K

The initial sample did not provide sufficiently clear evidence for a definitive feature decision.

SCALABILITY

Expanded to 100K

The dataset was scaled to approximately 100K users to strengthen the evidence base.

INTERPRETATION

Avoid overclaiming

Directional differences should be separated from statistically significant findings.

09 · BUSINESS IMPACT / CONCLUSION

Business Impact / Conclusion

The analysis gives the SaaS company a structured way to evaluate whether the AI feature supports conversion, engagement, and user behavior.

Because the available evidence does not establish a clear winner, the feature should not be treated as ready for broad implementation based on this analysis alone.

BUSINESS RECOMMENDATIONTreat the result as inconclusive and require further validated testing before making a broad rollout decision.
